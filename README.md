# netflix-content-analysis
Exploratory data analysis of Netflix titles using Python (Pandas, Matplotlib, Seaborn) 

## Dataset
- Netflix titles dataset (8,800+ records)
- Source: [add link, e.g. Kaggle dataset page]

## What I Did
- Cleaned the data: handled missing values and removed inconsistencies in titles,director,cast
- Parsed date columns for time-based analysis
- Built 10+ visualizations with Matplotlib and Seaborn

## Key Findings
- Movies make up 69.6%% of titles, TV shows 30.4%
- Most content was added in the year 2018
- The top country by number of titles is United States
- top tv show with most series is Grey anthony

## Tools Used
Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook
